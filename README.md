# PaperTodo

一个运行在 Windows 桌面上的轻量待办与灵感记录工具。

它不提供传统的任务列表主页。每一张待办纸和每一张笔记纸都是独立窗口：想到就记，做完就勾掉；需要安静一点时，把单张纸收成贴在屏幕边缘的桌面胶囊。

## 适合什么

- 把当天要做的事直接留在桌面上，而不是藏进另一个管理页面。
- 记录临时想法、会议片段、写作素材或 Markdown 笔记。
- 将当天待办和灵感沉淀为 Obsidian Vault 中的每日 Markdown 文件。

## 核心体验

### 待办纸

- 每张待办纸独立存在，可新建、编辑、勾选、删除和清理已完成项。
- 支持将笔记与具体待办关联，方便从待办直接打开相关思路或资料。
- 不使用“组”的层级或收纳逻辑；每条待办保持独立、直接。

### 灵感笔记

- 每张笔记都是独立桌面纸，可用于短想法、长文本和 Markdown 内容。
- 支持标签、图片，以及 Markdown 显示效果。
- 笔记可以和待办一样独立收成桌面胶囊，不必依附于任何分组。

### 桌面胶囊

- 待办纸和笔记纸均可单独折叠为胶囊，释放桌面空间。
- 胶囊可贴靠屏幕边缘，支持多显示器和拖动换边。
- 关闭按钮只在鼠标悬停胶囊时出现，避免平时干扰操作。

### Obsidian 同步

- 在设置中选择 Obsidian Vault、输出子目录和每天的同步时间。
- 可手动同步，也会在设定时间同步当天内容。
- 输出为按日期命名的 Markdown 日记，包含当天待办清单和当天更新的灵感笔记。
- 同步只更新文件中由 PaperTodo 管理的标记区块，保留你在同一篇日记中手写的其他内容。
- Vault 路径无效或输出目录越出 Vault 时不会写入文件。

## 隐私与数据

- 不需要账号，不依赖云端服务。
- 日常数据保存在应用本地目录中的 `data.json`，并维护本地备份。
- 配置 Obsidian 同步后，应用只会将 Markdown 写入你指定的 Vault 目录。

## 运行

### 使用发布版

在构建输出目录运行 `PaperTodo.exe`：

```powershell
.\输出\PaperTodo-v<版本号>\PaperTodo.exe
```

### 本地开发

需要 Windows 与 .NET 10 SDK：

```powershell
dotnet run --project .\PaperTodo.csproj
```

构建发布输出：

```powershell
dotnet build .\PaperTodo.csproj
```

构建后的文件位于 `输出\PaperTodo-v<版本号>\`。

## 使用入口

- **系统托盘菜单**：新建待办纸、新建笔记纸、打开设置、立即同步到 Obsidian。
- **每张纸的顶部操作区**：编辑、收成胶囊或关闭单张纸。
- **设置**：配置外观、快捷键、启动行为、胶囊行为和 Obsidian 同步。

## 技术栈

- Windows 桌面应用
- .NET 10
- WPF
